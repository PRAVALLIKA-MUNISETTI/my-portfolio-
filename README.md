# Pravallika Munisetti — Personal Portfolio

**Live Demo:** https://pravallika-munisetti-portfolio.lovable.app/

## Project Overview
Ee repository lo nenu (Pravallika Munisetti) tana personal portfolio website source code pettaanu. Website modern, clean, responsive design tho tayaravutundi — About, Skills, Projects, Internships, Achievements, Certificates (slideshow), and Contact sections unnai. Mobile-first layout, hamburger menu, and polished UI elements kuda include cheyyabadayi unnai.

## Features
- Responsive layout (desktop & mobile)
- Header with profile image and hamburger menu (sticky)
- Sections: Home, About, Skills, Projects, Internships, Achievements, Certificates, Contact (alternating image/content)
- Certificates slideshow/gallery
- Contact form integrated (Formspree or similar)
- Clean, flat/illustrated visual style with consistent spacing and professional colors
- Simple HTML, CSS, and JavaScript (no backend)

## Tech Stack
- HTML5
- CSS3 (responsive design, animations)
- JavaScript (vanilla) — slideshow, menu toggle, interactivity
- (Optional) Formspree for contact form handling
- No database / no server required for static hosting
